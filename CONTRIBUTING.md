# Contributing to Biopeia

Biopeia is in an architectural migration. Check the target repository's current instructions, owner, canonical design and scientific gates before acting.

1. Use an issue with a bounded outcome, scope, constraints and acceptance criteria.
2. Investigate first; distinguish observed facts from hypotheses and conclusions.
3. Implement only within existing authority; do not modify FROZEN evidence, RUNNING study inputs, or constitutional boundaries without required approval.
4. Submit a PR linking tests, precise revisions, evidence and limitations.
5. Keep authoritative scientific and architectural records in their owning locations.

Passing CI is not scientific acceptance. Negative and inconclusive findings must remain visible. Follow repository-specific AGENTS.md and governance where applicable.
