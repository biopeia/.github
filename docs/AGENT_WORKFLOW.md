# Biopeia Agent Workflow v1

**Status: proposed shared workflow; not an authorization to alter existing repository governance.**

## Operating chain

Project → Issue contract → responsible agent → investigation/implementation → PR and evidence → technical CI → authorized integration or escalation.

One agent coordinates each issue. Independent adversarial review is proportional to the impact and risk; another model agreeing does not alone establish independence.

## Issue contract

Each issue should state the outcome, scope, exclusions, domain, work class, risks, dependencies, acceptance criteria, evidence, baseline revision and required decision owner.

## States

Backlog, Ready, In Progress, In Review and Done; Blocked is used for unresolved dependencies and decisions. Done refers to completion of the bounded task, **not** confirmation of a scientific hypothesis.

## Research and architecture

The organism must not receive evaluator knowledge, scientific claims must have explicit scope and falsifiable evidence, and protected decisions remain with their authorized owner. An existing extracted repository is not an authorized cut-over. Do not initiate gated passes, including Pass 15, on the basis of project tracking alone.

Existing repository-specific agentctl and governance remain controlling until expressly revised.
